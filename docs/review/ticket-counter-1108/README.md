# Ticket dispenser and prize counter acceptance

Source `bf34a0994c1bf9e746f6b2d881944b9a8e08d078` descends from actual upstream `90c014cd70113e8e8b7966c23466e763a28845e6`. Issue #1108 was confirmed assigned and labelled nsoc26/level3 before coding. Six feature files add vanilla JS/CSS, Node tests, two script tags and the canonical test command. Games, SDK, generated registry, contributor rankings and the separate daily-token wallet are unchanged.

Validated parent game-over events award floor(final score / 100) once per opened iframe session. Score updates only supply a fallback final score; closing without a game-over event does not pay. SHA256 receipts persist under av_ticket_ledger without raw session tokens, including zero-ticket completions. Native Web Locks serialize read/modify/write across tabs, and successful storage writes precede any confirmed award. The booth is available from the catalog and Hall of Fame, redeems four local cosmetics once, and persists ownership/equipment across reloads. Cosmetics are a neon mouse trail, retro ticket sound, a local star portrait badge and a glowing game-window/portrait border. They never change official NSoC points.

Ten new Node tests and the complete canonical npm test pass. They cover floor boundaries and fractional scores, invalid inputs, zero-result and changed-score replay, 127 independent score totals, exact costs/ownership/slot checks, denied reads/writes, malformed/oversized ledgers, balance/revision/4096-receipt limits and unrelated-key preservation. Strict assets reports zero errors and 127 warnings; its entire output is byte-identical on clean upstream 90c014c. Registry --check passes for 123 games/13 contributors.

Chromium acceptance exercises the actual catalog, existing Cyber Tower Defense iframe, real SDK handshake and parent message validation; controlled scores are sent through that SDK without replacing app/game code. It verifies score-only/no payout, wrong parent source and wrong token rejection, final-score floor, duplicate end rejection, invalid final values, latest-score fallback, close without payout, and no persisted raw tokens. Two real tabs produce the expected combined balance under Web Locks; two purchases queued behind a held native lock charge one prize once. Real storage events update equipment across tabs. Native Canvas pixels appear and the trail stops requesting frames when idle; reduced motion removes it. Real Web Audio oscillators use the default square chatter and equipped triangle chime, respect master mute/zero volume/mid-sequence mute, and pause with reduced motion. No physical speaker/output assertion is made.

Native Tab/Space/Enter/Escape, return focus and post-redemption focus, Hall of Fame/reload ownership, all four prizes, 320/375/430/850/1360 containment and visually reviewed desktop/mobile screenshots pass. Quota denial, retry of an unsaved completed session, malformed data, lock denial and a throwing localStorage getter preserve saved data. Games still launch with a malformed wallet. Unrelated and daily-wallet canaries remain unchanged. Page errors and failed local resources are zero. Only legacy Google Fonts and Lucide CDN responses are stubbed. This static site serves the tested source directly; HTTP bytes and SHA256 match, without claiming a separate production bundle.

The ledger is device-local cosmetics, not a server-backed economy or anti-cheat authority. Clearing/editing browser storage changes the profile. There is no account sync/cash value. Bounds are 1,000,000 tickets, 4,096 receipt hashes, score <=100,000,000 and revision <=1,000,000,000; full receipt storage pauses new awards but retains prizes/redemption. Unsupported Web Locks/secure hashing or inaccessible/malformed storage disables mutation and explains the problem. Each opened game receives one award even if an internal restart reuses that parent session. The bounded roll lasts 2.4 seconds; audio uses the existing shared SoundEngine without closing its context. Reduced motion pauses visual/sound effects, not earned tickets.

## Reproduce

Check out the source commit and run npm test, node scripts/validate-games.js --strict-assets, and node scripts/build-registry.js --check. Serve it with python3 -m http.server 5292 --bind 127.0.0.1. Install Playwright and its Chromium browser in a separate test environment, then run acceptance-browser.mjs with PLAYWRIGHT_MODULE set to its index.mjs absolute path and ARCADE_SOURCE set to the checked-out source directory. Optional ARCADE_URL and ARCADE_EVIDENCE_DIR override localhost:5292 and ./ticket-acceptance. The harness records native API behavior and drives deterministic scores through the real SDK; it does not replace application code or use a debug mint API.

Artifacts are on a fork-only evidence branch outside the source PR diff. Hosted CI, maintainer approval/merge and official credit remain distinct later states.
