# Wallpaper Studio acceptance evidence

Source `aaca56f9827d2544a1acd79c620895b992e0ebc9` is a normal signed-off merge of actual upstream `afae02bf19b002af8336b5f3ff955de1882aca36` into the focused feature commit (original parent eb2f6e5). Issue #1109 was assigned with nsoc26/level3 before coding. The PR diff has five files: vanilla JS/CSS, Node tests, docs entry and canonical test command. No game, SDK, generated-registry or other contributor files are edited by this feature.

The docs sidebar opens Wallpaper Studio. It chooses 24 distinct registry games, composites their catalog Lucide icons and locally drawn neon card art, and offers 1920x1080, 3840x2160 and 1080x1920 presets. Synthwave Cyan/Pink, Matrix Green and Classic Amber, 0-100% CRT scanlines and a glowing center brand watermark are supported. Styling keeps the same selected games; Generate new mix reshuffles. Generation is lazy, cancellable, coalesced and yields in card batches. Only the newest generation publishes. Cancellation preserves the last completed image/selection; failed creation/encoding does not destroy it. toBlob requests a native lossless image/png download; object URLs/anchors are cleaned up and stale encoding callbacks cannot download an obsolete result. PNG uses normal browser lossless compression, without a ZIP/JPEG conversion or an assertion that PNG bytes are uncompressed.

Seven new Node tests plus the full canonical npm test pass on the merged source. Tests cover actual-registry membership, unique random selections and deterministic seeded controls, invalid/duplicate metadata, input bounds, prototype-looking preset names and all 24 nonoverlapping cell bounds at all three resolutions. Strict assets passes with zero errors and 124 warnings; the complete output matches a clean afae02 baseline byte for byte. Registry --check and SHA256 metadata integrity pass for 123 games/13 contributors.

The actual docs page was exercised in Chromium with the real generated registry and existing Lucide 1.77.0 UMD response (exact captured bytes/hash retained; Google Fonts omitted). All 24 catalog SVG icons were rasterized natively. A recurring task ran during batched drawing, confirming cooperative scheduling. Native downloads for Full HD, 4K and phone sizes have valid PNG signatures/IHDR dimensions and decode through createImageBitmap; decoded complete RGBA SHA256 equals the ready canvas at each size. Retry produces the same phone pixels. This checks actual downloaded files, not only canvas width attributes. Style changes preserve game IDs while changing pixels for tints, scanline 0/100 and watermark on/off. Rapid controls publish only final configuration. Native keyboard controls, proper slider label, 320/375/430/850/1440 containment, 44px button targets and reduced-motion static rendering pass.

Adverse cases include delayed native SVG delivery during cancellation, staging-canvas release, throwing/null toBlob, denied anchor click, stale delayed encoding callback, too-small catalog, unavailable drawing context and unavailable icon library. They preserve the prior ready image and recover; no stale download or retained download URL/anchor remains. These injections are scoped to failure/cancellation tests, not normal exported images. Page errors and failed local resources are zero. Defaults and generation never write user storage or upload content.

Desktop/mobile UI, full-resolution phone output and the actual 4K output viewed through a native 1920px image preview were visually reviewed. Direct 6.7MB image-tool payload exceeds its display cap; native PNG decoding/hash checks and the browser preview verify the original artifact without changing it. Static HTTP source bytes match the tested JS SHA256. This is a static site, with no separate bundler artifact. Icon-library failures use disclosed controller-card artwork; missing local brand image uses AV lettering. This exports card artwork, not screenshots of running games. Hosted CI, maintainer review/labels/merge and official credit remain separate.

## Reproduce

Check out the source commit. Run npm test, node scripts/validate-games.js --strict-assets, node scripts/build-registry.js --check and node scripts/verify-registry-integrity.js. Serve it with python3 -m http.server 5293 --bind 127.0.0.1. Install Playwright/Chromium in a separate test environment. Run acceptance-browser.mjs with PLAYWRIGHT_MODULE pointing to Playwright's index.mjs and ARCADE_SOURCE to the source checkout. Optional ARCADE_URL and ARCADE_EVIDENCE_DIR override localhost:5293 and ./wallpaper-acceptance. The included, unmodified Lucide fixture is used by default; its original license header remains intact. The portable harness was rerun separately against this exact source with passing pixel/failure checks.

The branch holds review artifacts only; the source PR does not contain screenshot binaries or this captured third-party fixture.
